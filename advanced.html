Express multi-step logic clearly.

Advanced SQL is less about cleverness and more about choosing the construct that keeps grain, order and intent visible.

CTEs: name the steps

WITH customer_revenue AS (
  SELECT customer_id, SUM(amount) AS revenue
  FROM orders
  WHERE status = 'paid'
  GROUP BY customer_id
),
ranked AS (
  SELECT *,
         DENSE_RANK() OVER (ORDER BY revenue DESC) AS revenue_rank
  FROM customer_revenue
)
SELECT *
FROM ranked
WHERE revenue_rank <= 10;

CTEs improve readability and reuse within one statement. They are not automatically faster; inspect the plan.

Window functions

Window functions compute across related rows without collapsing them.

SELECT
  customer_id,
  order_date,
  amount,
  SUM(amount) OVER (
    PARTITION BY customer_id
    ORDER BY order_date, order_id
    ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
  ) AS running_spend,
  LAG(amount) OVER (
    PARTITION BY customer_id ORDER BY order_date, order_id
  ) AS previous_amount
FROM orders;

Deduplication: latest record per entity

WITH ranked AS (
  SELECT
    p.*,
    ROW_NUMBER() OVER (
      PARTITION BY customer_id
      ORDER BY updated_at DESC, profile_id DESC
    ) AS rn
  FROM customer_profiles p
)
SELECT *
FROM ranked
WHERE rn = 1;

Always specify a deterministic tie-breaker after the timestamp.

Window frames

AVG(daily_revenue) OVER (
  ORDER BY metric_date
  ROWS BETWEEN 6 PRECEDING AND CURRENT ROW
) AS rolling_7_row_average
Rows are not always daysA 7-row frame equals seven days only if your input has exactly one row per date and no missing dates. Build a date spine when continuity matters.

Recursive CTE

WITH RECURSIVE org AS (
  SELECT employee_id, manager_id, employee_name, 0 AS level
  FROM employees
  WHERE manager_id IS NULL
  UNION ALL
  SELECT e.employee_id, e.manager_id, e.employee_name, o.level + 1
  FROM employees e
  JOIN org o ON e.manager_id = o.employee_id
)
SELECT * FROM org;

Pivot through conditional aggregation

SELECT
  region,
  SUM(CASE WHEN quarter = 'Q1' THEN revenue ELSE 0 END) AS q1,
  SUM(CASE WHEN quarter = 'Q2' THEN revenue ELSE 0 END) AS q2,
  SUM(CASE WHEN quarter = 'Q3' THEN revenue ELSE 0 END) AS q3,
  SUM(CASE WHEN quarter = 'Q4' THEN revenue ELSE 0 END) AS q4
FROM sales
GROUP BY region;

Performance habits

  • Select only required columns and rows.
  • Filter early when it preserves meaning.
  • Index columns used in selective filters, joins, and ordering.
  • Avoid functions on indexed columns in predicates when a range condition is possible.
  • Use EXPLAIN; do not guess.
  • Remove accidental repeated work, not readable CTEs by reflex.
