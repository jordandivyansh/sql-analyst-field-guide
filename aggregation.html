Module 04 · Metrics

Control the grain of every metric.

Aggregation is where business definitions become numbers. The SQL is short; the reasoning about denominators and grain is the real interview.

GROUP BYConditional metricsRatios

Aggregate functions

COUNT

Rows, non-NULL values, or distinct entities.

SUM / AVG

Additive values and averages; both ignore NULL arguments.

MIN / MAX

Extremes for numeric, date, and sortable text values.

SELECT
  region,
  COUNT(*) AS order_count,
  COUNT(DISTINCT customer_id) AS customers,
  SUM(amount) AS revenue,
  AVG(amount) AS average_order_value
FROM orders
GROUP BY region;

WHERE vs HAVING

WHERE

Filters rows before groups exist. Usually more efficient when applicable.

HAVING

Filters aggregated groups after GROUP BY.

SELECT region, SUM(amount) AS revenue
FROM orders
WHERE order_date >= '2026-01-01'
GROUP BY region
HAVING SUM(amount) > 100000;

Conditional aggregation

This is one of the highest-value analyst patterns: multiple filtered metrics in a single scan.

SELECT
  DATE_FORMAT(order_date, '%Y-%m') AS month,
  COUNT(*) AS orders,
  SUM(CASE WHEN status = 'paid' THEN 1 ELSE 0 END) AS paid_orders,
  SUM(CASE WHEN status = 'refunded' THEN amount ELSE 0 END) AS refund_value,
  100.0 * SUM(CASE WHEN status = 'paid' THEN 1 ELSE 0 END)
        / NULLIF(COUNT(*), 0) AS paid_rate_pct
FROM orders
GROUP BY DATE_FORMAT(order_date, '%Y-%m');

Weighted vs unweighted averages

Average of averages is often wrongStore-level average order values must be weighted by order counts when calculating the overall average.
-- Correct weighted average from grouped data
SELECT
  SUM(avg_order_value * order_count) / SUM(order_count) AS overall_aov
FROM store_summary;

Counting business entities correctly

QuestionExpressionRisk
How many rows?COUNT(*)May count repeated entities.
How many customers?COUNT(DISTINCT customer_id)Check whether customer ID can be NULL.
How many paid orders?SUM(status='paid') in MySQL or CASEUse CASE for portability.
How many active days?COUNT(DISTINCT activity_date)Date truncation and timezone matter.

Grouping sets: concept to know

Other databases support ROLLUP, CUBE, and GROUPING SETS for multiple aggregation levels. MySQL supports WITH ROLLUP.

SELECT region, product, SUM(revenue)
FROM sales
GROUP BY region, product WITH ROLLUP;
